# Segurança

## Relatando uma vulnerabilidade

Não publique vulnerabilidades exploráveis, dados pessoais, arquivos de mídia ou
logs completos em uma issue pública. Use o recurso **Private vulnerability
reporting** do GitHub, caso ele esteja habilitado no repositório.

Se o recurso privado não estiver disponível, abra uma issue sem detalhes
sensíveis apenas para solicitar um canal de contato.

## Dados processados

O aplicativo processa vídeo e áudio localmente. A rede é usada para baixar
pacotes e modelos. O programa não exige chave de API nem deve solicitar senha,
token do GitHub ou credencial de serviço externo.

Baixe Python, VLC, drivers e dependências somente de fontes oficiais. Revise as
alterações antes de executar arquivos `.bat` recebidos de terceiros.
